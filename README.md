# ☕ Moi Menu — القائمة الرقمية التفاعلية

---

## 🌟 نبذة عن المشروع
**Moi Menu** هي منصة قائمة طعام إلكترونية وسريعة صُممت خصيصاً لمطعم وكافيه **Moi** (الموجود داخل حرم الجامعة). تهدف المنصة إلى توفير تجربة رقمية عصرية ومرنة للطلاب والزوار للوصول إلى كافة الوجبات والمشروبات مباشرة عبر مسح رمز الاستجابة السريعة (**QR Code**) من هواتفهم المحمولة.

> **الشعار:** *قهوة · حلويات · لحظات تستحق المزيد*

---

## ✨ المميزات الرئيسية
* 📱 **واجهة متجاوبة بالكامل:** متوافقة مع جميع أحجام الهواتف والأجهزة الذكية.
* ⚡ **سرعة عالية ووصول فوري:** فتح المنيو فوراً بدون الحاجة لتنزيل أي تطبيق.
* 🔍 **محرك بحث وتصفية ذكي:** البحث التفاعلي السريع والتنقل بين الأقسام بضغطة زر.
* 🍕 **تنوع الأقسام:** يدعم أكثر من 18 تصنيفاً (المشروبات، وجبات الفطور، الأطباق الإيطالية، السندويشات، والحلويات).
* 🏷️ **شفافية الأسعار:** عرض متكامل لأسعار الأصناف بالدينار العراقي (د.ع) وخيارات الوجبات.

---

## 🚀 طريقة التشغيل والرفع (Deployment)

1. **الرفع عبر GitHub Pages:**
   * تأكد من تسمية ملف المنيو الرئيسي بـ `index.html`.
   * انزل إلى إعدادات المستودع **Settings** ثم اختر **Pages**.
   * اختر الفرع الرئيسي (`main`) واضغط على **Save**.

2. **التحديث والتعديل:**
   * يمكنك تعديل الأسعار والأصناف بسهولة في أي وقت من خلال فتح الملف والتعديل المباشر عليه.
